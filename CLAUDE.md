# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Dino World is an offline-capable, iPad-first 3D web game for ages 12 and up, built with Vite, TypeScript and Three.js and no UI framework. It makes no network calls and has no ads or tracking. Keep it that way. It is a story game: a T-Rex breaking out of a dinosaur theme park during a storm. The park, island, company and characters are original (Primordia park on Kessick Island, run by Halcyon Genetics; the hero is Specimen T-07). Keep it that way: no names, logos, music or recreated scenes from existing films or games. It was split out of Mini Mix (`../mini-mix`), and `src/` outside `src/game/` is a copy of Mini Mix's shell and engine. When you fix a bug there, consider whether Mini Mix needs the same fix.

## Commands

Docker is the supported workflow, so you don't need Node installed locally:

```bash
docker compose --profile dev up            # Vite dev server, hot reload → http://localhost:5175
docker compose --profile prod up -d --build  # nginx static build → http://localhost:8082 (PORT=… to change)
WATCH_POLLING=true docker compose --profile dev up   # if edits don't trigger reloads
docker compose --profile dev up --build -V           # after changing package.json
```

To typecheck without local Node: `docker compose --profile dev run --rm dev npm run typecheck`.

With Node installed locally (`npm ci` first): `npm run typecheck` (tsc --noEmit, strict, noUnusedLocals/Parameters), `npm run build`, `npm run dev`.

The project has no test suite and no linter. `npm run typecheck` is the main correctness check. The build targets `es2020`/`safari14` (iPadOS 14+ Safari), so don't use newer runtime APIs without a fallback.

## Architecture

- **Routing** (`src/main.ts`): hash-based. `#/` is the title screen (`splash.ts`/`splash.css`: a DOM/SVG storm scene with the Story, Rampage and Settings menu and a Beta stamp), `#/settings` is the settings page (`settings.ts`; `buildSettings()` builds the same panel into any element, which the in-game pause menu uses), and `#/story` and `#/rampage` mount the game in that mode through `shell.ts`. Each mount returns an unmount function, and `route()` calls it before mounting the next view. Changing the language re-runs `route()`, so views read strings when they mount.
- **Game contract** (`src/types.ts`): the game is a `GameDef` exported from `src/game/index.ts`. `start(ctx, mode)` must return a cleanup function that tears down everything it created: the renderer, geometries, listeners, timers and audio. The shell owns only the back-to-title button; the game must leave `ctx.topInset` free for it, and can call `ctx.exit()`. There is no score or star system.
- **Three.js**: `src/game/index.ts` lazy-loads `game.ts` with dynamic `import()`, so Three.js lands in a separate chunk. Keep every Three.js import out of the eager graph: `levels.ts`, `progress.ts`, `species.ts` and `strings.ts` are imported by the title screen and settings, so they must stay free of it.
- **Game flow** (`src/game/index.ts`): plain DOM screens around the 3D level. Story mode goes level select → mission brief → level → debrief (next level or retry). Rampage first shows a map picker (every map in `src/game/maps/`, each with an SVG sketch from `mapthumb.ts`; quitting returns to it), then plays that island with no goals and respawning targets; a map tried from the editor skips the picker. Each level is a fresh `runDino(ctx, { level, onEnd, onRestart, onQuit })` from `game.ts`, torn down before the next.
- **Levels** (`levels.ts`): data, not code. A `LevelDef` holds its name, place, brief, goals (`escape`, `smash`, `scare`, `free`, `destroy`, `generators`, `sink` with counts), rangers, fences, power, boat departures, an opening shot, a start (`cage` or just outside the broken paddock), an optional time limit, park-radio lines and a `ready` flag. Levels with `ready: false` show as "coming soon" (all five are ready now). A new goal kind needs counting in `game.ts` (`progress()`), a label in `strings.ts` and the brief text in `index.ts`.
- **Progress** (`progress.ts`): levels completed in order, and which species are unlocked for Rampage (the T-Rex hero always is; freeing a caged dinosaur unlocks its species). Stored under `dinoworld:progress`; settings can reset it.
- **3D modules**: `game.ts` (the level: input, camera, HUD, objectives, radio, pause menu), `world.ts` (terrain and plants), `trees.ts` (modelled broadleaf and palm tree variants, merged and vertex-coloured, drawn as one InstancedMesh each, swaying in the wind in the shader), `weather.ts` (storm sky dome, GPU rain that follows the camera, lightning and thunder, rain sound; the level adds `weather.flash` to its lights), `dinos.ts` (the dinosaurs), `park.ts` (cages, jeeps, visitors and rangers, including the knocked-down pose; a jeep is bitten to tip it over onto its side (`tipCar`, a heave then a fall past its balance point, with bounces; the `smash` goal counts when it lands), and dinosaurs walking into one shove it slowly along, upright or on its side (`pushCar`, against a footprint from `carFootprint`)). Species are in `species.ts`; to add one, add it to `DINOS` and a builder to `BUILD` in `dinos.ts`.
- **Hazards and destruction**: `security.ts` (rangers: patrol → aim → shoot darts, real projectiles that can be dodged; they flee when charged or roared at, and can be knocked flat; within reach the bite button snatches one up by the jacket: the dinosaur shakes them (`Rig.thrash`) and flings them aside, and they lie out cold for the rest of the level), `buildings.ts` (Main Street, `TOWN` in `world.ts`, plus the boat shed at the docks: buildings designed in metres and drawn at `SCALE` (1.5) to match the people, made of pre-broken panels, with furnished rooms inside (floor slabs are `fixed` pieces that never come away; furniture pieces can be bitten out); biting into one (the roar button turns into bite when facing a wall up close) tears out the pieces nearest the jaws, `hp` bites wreck it (the `destroy` goal), but it never collapses and a charge only shakes it), `fences.ts` (the `FENCE_LINES` in `world.ts`: live sections zap and throw the dinosaur back, dead ones are torn down by a charge). `game.ts` owns energy: darts and zaps drain it, it regenerates after a few seconds, and at 0 the dinosaur is sedated and wakes at the last checkpoint (set at the start and on every goal step), keeping goal progress. Levels opt in with `rangers` and `fences` in `levels.ts`; Rampage has both.
- **World maps** (`src/game/maps/`): each island layout is plain data, a `MapDef` (`maps/types.ts`, no Three.js) in its own file that default-exports it; every file in the folder except `index.ts`, `types.ts` and `source.ts` is picked up by `import.meta.glob` into `MAPS`. A map holds the play-area size, the coast (land starts out south of the straight `shore` line, then `coast` brush strokes, in order, paint land or wash it away as sea; `coastAt()` in `shapes.ts`; a beach is added along every coast), rolling relief, freehand hills (strokes), lakes, volcanoes and plateaus (`Shape`: a circle or a freehand outline of points), roads (strokes; drawn as muddy dirt tracks with tyre ruts, a canvas texture in `world.ts`), the hero's paddock, cages, the three sites, buildings (`House`: centre in world units, size in metres, `style` from `STYLES` in `buildings.ts`), fences, visitors, guard posts, jeeps (`cars`: position and heading in degrees), plant counts and a seed. Beyond the play area the ground is always dense jungle out to its edge (packed cheap trees, then leafy canopy masses), except on the sea side. A level picks one with `map` (default `kessick`; its `start` and `intro` positions are on that map); Rampage plays the one picked in its map picker (`RunOpts.map`), or the map being tried from the editor (`setTrial`). `useMap()` in `world.ts` copies the map into the exported layout objects (`TOWN`, `LAKES`, `VOLCANOES`, `ROADS`, `HOUSES`, `CAGE_SPOTS`, `PADDOCK`, …, filled in place, plus `let` bindings `HALF` and `SHORE`) before a level is built, so modules keep reading those; place things relative to them, never at fixed coordinates. 2D shape maths (signed distance to outlines, strokes, simplifying freehand input) is in `shapes.ts`. `coastDist()` in `world.ts` (negative on land, positive at sea, sampled on a 2 m grid) drives the beach (flattened and sanded) and sea floor, the sea mesh, `inWater()`, planting and the surf; `SHORE` is the shore at the docks, where the pier runs out (+z). Guard posts get a ranger in Rampage and in levels that have rangers (at least one per post); visitors stand at their spots in every level; every level puts all the map's jeeps (kept clear of trees). Rampage has exactly what the editor shows, the map's jeeps and visitors and nothing more; story levels put a visitor beside each jeep, add random jeeps when their goals need more, and a Main Street crowd when buildings are a goal.
- **Map editor** (`mapedit.ts`, lazy-loaded at `#/map` or `#/map/<id>`): the real 3D world drawn from above (rebuilt a moment after each change) with the layout on top. Tools put down and drag cages, buildings, fences, people, guards and jeeps (a jeep put on a road lines up with it), draw roads, hills, lakes, plateaus, volcanoes, freehand (a tap makes a round one), paint land and sea with brushes (All sea / All land start the coast over; the coastline is traced on top), erase, and reseed the trees and rocks; the side panel edits the selection's numbers or the map's settings. Undo/redo; unsaved changes are drafts in localStorage (`dinoworld:mapdrafts`). Save (dev server only) POSTs to a dev-only Vite plugin in `vite.config.ts` that writes `src/game/maps/<id>.ts` (the source comes from `maps/source.ts`); Download gives the same file anywhere. Try it opens `#/rampage/try/<id>`, Rampage on the draft, and leaving it returns to the editor. Each level's start and opening shot on the map are shown too.
- **Story sites** (`world.ts`): `TOWN` (Main Street), `POWER` (the power station) and `DOCKS` are `Site`s, levelled by `groundY()` and kept clear of trees; past the coast the land drops into the sea (wadeable; `inWater()`). `station.ts` has three generators: each takes `BITES` (5) bites, every bite tearing a gash in its housing (an instanced mesh per generator, added after baking), flinging a panel off (one instanced mesh for the yard) and making it lean, spark and smoke more; a charge only bounces off. Killing them in any level that allows it counts `generators`, and when the last dies `game.ts` calls `blackout()` (fences dead, town lights off, every paddock opens and its dinosaur is freed and unlocked). `docks.ts` has a pier and four launches; the pier (`PIER` in `world.ts`) is walkable because walkers stand on `floorY()`, which is `groundY()` plus the deck (the terrain itself stays under the water); `LevelDef.boats` schedules their departures, a charge capsizes one (`sink` goal), and the level fails when too many get away to meet the goal. `power: 'off'` levels start after the blackout.
- **Opening shots**: every `LevelDef` has an `intro` camera glide (`from` → `to`, looking at `look`) shown under a letterboxed title for `INTRO` seconds; input, the timer, rangers and boat departures wait for it, and any tap or key skips it. `start` can also be `[x, z, heading]` to begin a level somewhere other than the paddock.
- **Draw calls** (`merge.ts`): iPads choke on draw calls, so every model is passed through `bake()`, which merges static parts into their nearest moving joint and bakes plain colours into vertex colours (one mesh per joint). Mark meshes whose material is swapped later with `userData.keep`, and materials whose colour changes with `userData.dynamic`. Intact buildings and cages are drawn merged and swap to their separate pieces on first contact. Add anything that moves on its own (e.g. people on a boat) after baking its parent. Check the cost with the in-game frame-rate readout (settings → Show frame rate), which also shows draw calls.
- **See-through** (`seethrough.ts`): anything between the camera and the dinosaur is dithered out to about 30% in the shaders (patched in with `onBeforeCompile`, so there are no extra draw calls or material swaps). Mark objects it must leave alone (dinosaurs, ground, roads, water) with `userData.noFade`; they get private copies of bake()'s shared materials (`userData.shared`), so those still fade on everything else.
- **Quality** (`engine/storage.ts`, settings): Auto (default) first swaps the play area's trees to their cheap models (`world.setTreeDetail`), then steps the pixel ratio down to 0.7, then turns off shadows when frames average over 24 ms, and steps back up when they're fast (full trees last, and not again after they've been dropped twice); High and Low are fixed (Low also uses the cheap trees and halves the rain and the shadow map).
- **Rampage**: a score (`POINTS` in `game.ts`) with a combo multiplier for mayhem within 4 s of the last, a best score saved in progress and shown on the title screen, and more rangers (`security.reinforce`) every 2,500 points.
- **Dinosaur models** (`dinos.ts`): no asset files. A body is a list of spine `Station`s (z, height, half-width, half-height, belly drop) from tail tip to snout; `skinnedBody()` sweeps a cross-section through them into one `SkinnedMesh` and skins it to a pelvis bone, a tail chain and a chest/neck/head chain. Horns, jaws, eyes, plates and wings are attached to the bone at their position with `attach()`. Legs (`buildLeg`) are hip/knee/ankle/foot groups so `animate()` can lift and plant feet. Skin is a scale-and-stripe colour and bump texture painted on a canvas per species colour set (`skinMaterial`). Every swept geometry goes into `owned` and is freed by `disposeDinoAssets()`.
- **Controls**: touch uses a joystick wherever the finger lands plus on-screen buttons. On a computer, a click captures the mouse (pointer lock) for mouse look; WASD/arrows move, click/E/R roars or bites, Space jumps, and Esc/P pauses. Releasing the mouse pointer pauses the game.
- **Three.js disposal**: geometries, materials and skin textures are shared at module level in `dinos.ts`/`park.ts` and freed by `disposeDinoAssets()`/`disposePark()`; `weather.dispose()` frees the storm. Per-run resources go through a local `keep()` helper into a disposables list. `runDino`'s cleanup must call all of these plus `renderer.dispose()`.
- **Audio** (`src/engine/audio.ts`): every sound effect is synthesized with Web Audio; there are no sound files and no speech (the game has no voice at all). `ambience()` is the low drone that `game.ts` swells with `tension` (sightings, hits); `toneLoop`/`noiseLoop` carry the station's hum and the surf, mixed by distance. `main.ts` wires up iOS audio unlocking.
- **Storage** (`src/engine/storage.ts`): `load`/`save` wrap localStorage with the `dinoworld:` prefix and swallow errors.
- **Offline**: `public/sw.js` is registered only in production builds. Navigations are network-first and other same-origin GETs are cache-first.

## Conventions

- **i18n**: English and Danish (`src/i18n.ts`). `L(x)` picks the current language. Shell strings live in `UI`; the game's strings are in `src/game/strings.ts`, typed as `Record<Lang, typeof en>` so TypeScript flags any missing Danish string. Every new user-facing string, including spoken prompts, needs both languages.
- **Tone (12+)**: realistic and moody, not cute. People get scared, knocked down and run away; nobody is hurt, there is no blood and nobody dies. The game relies on reading: briefs, objectives, and park radio as subtitles (`radio()` in `game.ts` shows the line with a crackle; nothing is spoken).
- **iPad first**: the page sets `touch-action: none`, blocks pinch-zoom and long-press menus, respects safe-area insets and supports multi-touch through pointer ids. DOM UI animates with `transform` and `opacity` only.
- **Settings**: the title menu's Settings item (under Story and Rampage) opens `#/settings`. In a level, the pause menu's Settings entry opens the same panel (`buildSettings(…, { inGame: true })`) over the paused level without touching the route, so the paused level stays mounted underneath; closing it (or Esc) returns to the pause menu. In game, sound and the frame-rate readout apply at once, graphics quality and language take effect from the next level (the panel redraws itself in the new language but doesn't re-run `route()`), and progress reset is left out (it's on the title screen's settings).
